## Project 1: Proxmox Home Server (Homelab)

### Description
Designed and maintained a personal **Proxmox VE homelab** to gain hands-on experience with virtualization, networking, and system administration. I was responsible for planning the environment, deploying virtual machines, configuring services, and documenting the system architecture.

### Technologies & Tools
- Proxmox VE (Hypervisor)
- Linux & Windows Virtual Machines
- Networking & DNS services

### Key Services & Virtual Machines
- **Pi-hole (DNS & Network Filtering):**
  - Network-wide DNS server
  - Blocks ads, trackers, and unsafe domains
  - Provides visibility into DNS traffic
- **Minecraft Server (Linux VM):**
  - Internal-only server hosted on the home network
  - External access restricted via VPN
- **Windows Virtual Machine:**
  - Used for learning IT administration
  - User management, permissions, and file access testing
  - Safe sandbox for system experimentation

### Outcomes
- Practical experience with virtualization and hypervisors
- Improved understanding of networking and DNS
- Exposure to secure service hosting and infrastructure planning

### Roadmap
Planned future additions include:
- WireGuard VPN for secure remote access
- TrueNAS VM for backups and centralized storage
- Nextcloud for private file and photo hosting
- Improved monitoring and automation

> *Note: This homelab is a learning environment, not a production system. Configurations may change frequently as new services are tested.*

## Project 2: PythonScript_TaxAssist

### Description
Developed **TaxAssist**, an interactive Python command-line application that estimates **Canadian federal and Saskatchewan provincial taxes**. The tool collects user income sources and deductions, then calculates taxes, CPP, and EI estimates. This project was completed independently as an educational exercise.

### Technologies & Tools
- Python 3 (Standard Library only)
- Command-line interface (CLI)

### Features
- Prompt-based entry for multiple income sources
- Supports slip tagging (T4, T4A, T5, T3, or none)
- Handles investment income:
  - Capital gains (50% taxable)
  - Dividends (simplified)
  - Interest income
- Deduction and credit support:
  - RRSP contributions
  - Tuition, medical expenses, childcare
  - Charitable donations (tiered credits)
- Outputs a full tax summary:
  - Gross and taxable income
  - Federal and provincial tax
  - CPP and EI estimates
  - Net income and effective tax rate

### Outcomes
- Strengthened Python programming and data handling skills
- Improved understanding of Canadian tax structures
- Experience building user-friendly CLI tools

> *Disclaimer: This tool is for educational purposes only and is not professional tax advice.*

## Project 3: Toothbrush Tango 🪥 (Plaque Blast)

### Description
Created **Toothbrush Tango**, a 2D arcade survival game using **Pygame**. In this project, I designed gameplay mechanics, implemented collision detection, and developed progressive difficulty logic where the enemy becomes stronger as the player collects items.

### Technologies & Tools
- Python
- Pygame

### Gameplay Overview
- The player controls a toothbrush
- Collect sanitary items (toothpaste, soap, water) to increase score
- Avoid a germ enemy — collision results in game over
- Each collected item increases enemy speed by 10%

### Features
- Title and game-over screens
- Score HUD and pause functionality
- Randomized collectible spawns
- Multiple collectible sprites
- Dynamic enemy movement and increasing difficulty

### Outcomes
- Applied game loop, event handling, and collision mechanics
- Practiced object-oriented design in Python
- Gained experience with real-time gameplay balancing
